Project 01 · Hardware

Custom PC Build

Solo project · [date built] · Documented through disassembly and reassembly

Project Description

I designed and built a desktop computer from parts I selected and bought myself. The PC needed to handle two demanding jobs: high-refresh-rate gaming and running CAD software for my engineering classes. The main challenge was choosing compatible parts that met both needs within my budget [budget, if you want to share].

My Role

This was a solo project. I researched and chose every part, checked compatibility, assembled the system, installed the software, and tested it. For this portfolio, I partly took the PC apart again to document each part and explain what it does.

My Process

  • Set requirements: defined what the PC had to do (gaming at my monitor's 165 Hz refresh rate, and smooth CAD) before choosing any parts.
  • Selected parts: used PCPartPicker to choose parts and check that they were all compatible, and compared recommended parts from YouTube build and review videos. I also kept cost in mind, for example by choosing a CPU without built-in graphics since I was using a dedicated GPU.
  • Assembled and tested: followed YouTube build guides step by step, which made the main assembly straightforward. The hardest part was the wiring. To keep the inside looking clean, I used velcro cable ties for cable management.
  • Troubleshooting: after installing a Scythe RGB fan, its lights worked but the fan did not spin. I'm currently troubleshooting this by checking that the fan's motor cable is connected to a fan header and that the fan is enabled in the BIOS fan settings.
  • Documented: removed the SSD, power supply, CPU cooler (to show the CPU), GPU, and RAM, photographed each one, then reassembled and re-tested the system.
